# THE UNLISTED TIER — AND WHY IT IS NOT NAMED HERE (rewritten 2026-08-21).
#
# Until today unlisted pages were served under one prefix, /x/, and every agent below was asked
# not to crawl it. The structure migration retired that prefix: a page is born at its final path
# and never moves, and being unlisted is a WORD on its registry row rather than a place it is kept.
#
# So this file could only ask for the same protection by DISALLOWING THIRTY-EIGHT INDIVIDUAL URLS
# — which means publishing, in the one file every crawler fetches first, exactly the list the tier
# exists not to publish. A robots rule is advisory; the URL it names is not. That trade is a loss,
# and it is refused.
#
# WHAT PROTECTS AN UNLISTED PAGE NOW, all three checkable:
#   1. the page's own `noindex` meta, in its bytes — the authoritative signal, which every crawler
#      honours and which no robots rule can override;
#   2. absence from sitemap.xml — asserted exactly, in both directions, by tools/check-discoverable.js;
#   3. absence from /reports and from every listed page's links — asserted by tools/check-pages.js A6.
#
# Stated plainly, as the 2026-08-20 version of this note was: none of this is a wall. An unlisted
# page is readable by anyone holding the link. It is asked not to be indexed, not hidden.
