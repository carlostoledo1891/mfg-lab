The eval nobody sells

Benchmarks ask whether a model can produce a right answer. The unasked question is whether a model can tell a real certificate from a convincing fake — which is the actual failure mode in AI-assisted mathematics, and the one this tree has documented on itself repeatedly: a probe collector that truncated 91 of 100 rows and called the result “returned”; a withholding gate that defaulted to PERMIT; a self-map mistaken for a contraction. Every one of those is a plausible-but-wrong artefact with a known ground truth.

A benchmark of n claim/certificate pairs, each labelled sound or unsound with the defect named, on which a model's discrimination rate is measured — and which is re-runnable by a stranger with no dependencies, unlike every incumbent eval.

The honest constraint, stated first because it decides the path

4 claims and 50 attacks is a seed, not a corpus. Nothing inferential is supportable at that size and it must not be described as a benchmark until it is one. The related evidence is discouraging on cost: the ai-verify probe run spent ~$42 for 12 usable rows, and the harness bug that caused most of that loss is fixed but the run has not been repeated. Collection is the expensive part and repeating it is a spend decision, not a code decision.

The cheap version, which is worth doing regardless: the mutants already exist. Every mutation.last_red record is a semantically broken artefact with a proof that it is broken. Harvesting what has already been generated costs nothing new.
